# v1.0.1

## Overview

GitHub Releaseの変更内容が分かりやすくなり、Chrome Web Storeへの提出までを安全に自動化しました。

- GitHub Releaseに変更概要と、リリース対象コミットの一覧・前回リリースとの差分リンクを掲載します。
- 公開前の承認を1回にまとめました。承認後は同じ検証済みZIPをChrome Web Storeへアップロードし、審査に提出します。
- リリースノート、バージョン、タグの整合性を公開前に確認します。
- Chrome Web Store提出ジョブでpnpmキャッシュを誤って初期化し、処理が停止する問題を修正しました。
